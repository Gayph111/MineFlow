# Вопросы для утверждения результата АЛРОСА

Геометрическое разбиение и иерархия связей реализованы по уточнению пользователя. Полный производственный эталон пока отсутствует.

| Тема | Что проверить у заказчика |
|---|---|
| Оси и контуры | Подтвердить, что JOIN в пределах горизонта и тела задаёт ось, а порядок строк задаёт её направление. Уточнить назначение копий контура и двух одиночных точек. |
| Разделение | Подтвердить правило P/R для контура, допустимость интерполяции RL и способ учёта касаний, совпадений с границей и нескольких контуров одного тела. |
| Связывание | Подтвердить геометрическую непрерывность как критерий и определить обработку нескольких кандидатов, включая отношение N:1. |
| Нумерация | Указать стартовую точку или первую ось, направление, приоритет типа и правило начала счёта заново. |
| Обозначения | Передать справочник кодов и полных названий типов. Подтвердить применение формата `350_5_N_OBD_P` к рабочим участкам и номера для известных пар. |
| Длины и Excel | Утвердить единицы, XY или XYZ, длину по оси либо по хорде, точность записи, состав листов и полей рабочего файла. Приложить обработанный эталон. |

Сопроводиловка подтверждает обозначение для исходной оси JOIN 1538. Ось делится по предварительному правилу на два участка. Обозначение образца сохранено на листе осей с источником.
