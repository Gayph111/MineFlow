# Условия производственной приёмки

Выбранное по уточнению пользователя геометрическое разбиение P/R и связывание по непрерывности являются предварительными. Правила АЛРОСА, справочник типов и эталон схемы Excel пока отсутствуют. Программа оставляет итоговые номера неподтверждённых объектов пустыми. Предварительная нумерация по настройкам включается отдельно.

На границе, при невалидном или неоднозначном контуре и при нескольких кандидатах на пару требуется ручное решение. Для одиночных точек требуется недостающая геометрия или подтверждение особого типа объекта. Копии контура на исходном листе остаются доступными в режиме исходных осей.

Сцена показывает оси и контуры. Для 3D нужны исходные XYZ и системный драйвер OpenGL. Из одного набора осей и контуров объём сечений и геология между горизонтами не выводятся.

В выходной книге сохраняются исходные формулы и типы. Excel может обновить кэш формул при открытии. XLSX на выходе доступен без пароля. Настраиваемые проекты сохраняют путь к книге и параметры, а пароль запрашивается при открытии.
