# Аудит исходных материалов

- «КЕЙС № 3.pptx», слайды 3–5. Требуются ввод тел и маркировок, выбор столбцов Excel, длина, нумерация по положению и типу и сохранение связки Порода — Руда. VBA указан как предпочтительный подход.
- «сопроводиловка.pptx», слайды 1–3. Указаны поля и пример `350_5_N_OBD_P`, `ГПР`, JOIN 1538, координаты, число 94,4 и точная длина 94,409991. Схема показывает оси и границу рудного тела.
- «Осевые для Моя профессия ИТ.XLSX». Защищённая OOXML-книга содержит листы «выработки» (394 строки, 76 групп) и «контуры рудного тела по горизон» (1 153 строки, семь контуров). Все семь полигонов валидны. У 1732 и 1733 на −500 последовательность вершин совпадает с контуром с учётом циклического сдвига. У двух групп есть только одна точка.

Исходные заголовки в порядке Excel:

```text
EAST | NORTH | RL | STRING | JOIN | CODE | TUN_NAME | ПЕРИОД | ВИД_РАБОТ
СОПРЯЖЕНИЕ | РУДНОЕ_ТЕЛО | ГОРИЗОНТ | СЕЧЕНИЕ | SECTOR | ИМЯ_НА_КИРИЛЛИЦЕ
УКЛОН | СТАДИЯ | ДЛИНА | START | FINISH | ОБЪЕМНЫЙ ВЕС | ПРИМЕЧАНИЕ
```

Структура листов сохраняется. Ведомость считает длины по осям и от начала до конца. Расчётные поля и сведения из сопроводиловки хранятся на отдельном листе с идентификаторами исходных строк. Для производственного формата нужны [ответы заказчика](UNVERIFIED_REQUIREMENTS.md).
