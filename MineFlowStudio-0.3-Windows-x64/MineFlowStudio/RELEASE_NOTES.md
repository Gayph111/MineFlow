# MineFlow Studio 0.3

- Геометрическое разбиение действительных осей с сохранением всех исходных координат, идентификаторов и трассировки до строк Excel.
- Рабочие длины и категории по каждому участку. Длины рассчитываются в XY или XYZ, новые RL интерполируются при наличии двух высот.
- Предварительные пары по непрерывности. Неоднозначные кандидаты направляются на проверку. Доступны режимы по явному ID пары либо без автоматических связей.
- Нумерация с выбором старта, азимута, направления, приоритета и шаблона в пределах горизонта и тела. Присвоенные по настройкам номера остаются предварительными.
- Рабочий Excel с исходными листами, осями, участками, точками и парами. Валидация читает сохранённую книгу и сверяет размеры участков, категории P/R, координаты, номера, пары и исходные записи. Отчёты сохраняются отдельно.
- Сохранение проектов, список последних, завершение фоновых задач и защита исходной книги от перезаписи.
- 2D/3D для осей и участков, фильтры по телам и горизонтам, поиск, связанный выбор в таблицах, изометрия, полный экран и инспектор.
- Из рабочего интерфейса убран учебный режим. Синтетические данные и автоматические проверки остаются в исходниках.

## Открытые вопросы

Предварительное геометрическое разбиение и связывание выбраны для реализации по уточнению пользователя. Для производственной приёмки требуются утверждённый порядок нумерации, справочник типов, согласованный шаблон Excel и решение по спорным случаям. Отдельный список формируется в `UNVERIFIED_CASES.md`.
