# MineFlow Studio 0.3

Windows-приложение для просмотра и обработки осевых выработок в кейсе № 3 АЛРОСА. В комплекте рабочая книга, отчёт валидации и список случаев для подтверждения.

## Быстрый запуск

1. Распакуйте ZIP целиком. Запустите `MineFlowStudio.exe` рядом с папкой `_internal`. Сборка для Windows x64 включает Python и библиотеки. 3D использует системный драйвер OpenGL.
2. Нажмите **Создать проект…**, выберите исходный Excel и имя файла проекта. Введите пароль к Excel в появившемся диалоге. Кнопка **Открыть Excel** запускает обработку напрямую.
3. В разделе **Данные → Листы и столбцы** проверьте сопоставление, если заголовки отличаются от исходной книги кейса. В **Правилах** можно выбрать XY или XYZ, разделение, способ связывания и параметры нумерации.
4. Нажмите **Обработать** после изменения настроек. Переключатель **Участки / Исходные оси** меняет набор на схемах и в таблицах.
5. В **Экспорте** сохраните XLSX. Приложение проверит выгрузку и сохранит рядом отчёт и список спорных объектов. **Проверить результат** и **Отчёт проверки** доступны также в разделе **Проверки**.

Команда **Сохранить проект** записывает настройки в `.mineflow.json`. Файл проекта содержит путь к Excel. Пароль вводится заново при открытии. Сохранённые проекты доступны из списка последних.

## Разделение и связи

По настройке **Разделять по границе контура** оси разрезаются в точках пересечения с однозначным валидным контуром того же тела и горизонта. Точки исходной оси сохраняются. Для новых точек известная отметка RL вычисляется линейной интерполяцией. На каждой стороне отдельно рассчитывается длина осевой линии и расстояние между концами. Участки на границе, случаи без однозначного контура и неполные линии требуют подтверждения.

Режим **Непрерывность и один партнёр** предлагает пару между соседними участками одной оси, которые имеют общую конечную точку и разных типов. Для включения в пары каждому участку нужен ровно один кандидат. Можно переключиться на явный ID пары из Excel или отключить установление связей. Геометрические категории и связи имеют статус **UNVERIFIED** до утверждения заказчиком.

В **Нумерации по настройкам проекта** можно выбрать начальный номер, сортировку, азимут, стартовую точку, направление, приоритет категории и формат. Счёт ведётся внутри выбранной пары «горизонт и тело». У однозначной связки общий номер. Шаблон вида `350_5_N_OBD_P` требует CODE и явно введённого кода типа. Предварительная нумерация включается пользователем и имеет статус **UNVERIFIED**. Образец JOIN 1538 относится к исходной оси и сохранён со ссылкой на сопроводиловку.

## 2D и 3D

В 2D доступны выбор горизонта, тела, поиск и слои. В 3D горизонты можно включать отдельно в дереве. Перетаскивание левой кнопкой вращает сцену, средней сдвигает её, колесо меняет масштаб. Панель содержит ортографическую и перспективную камеры, виды вдоль осей, изометрию, вписывание, фокусировку и полный экран. Щелчок выделяет объект в таблице и инспекторе. Связанный участок подсвечивается другим цветом.

3D построен из исходных EAST, NORTH и RL и из вычисленных точек пересечений. Доступны исходные оси, участки и контуры. Реальных сечений в исходной книге нет.

## Рабочая книга

По умолчанию Excel открывается на листе **Участки**. Листы **Оси**, **Точки участков** и **Связи участков** дают идентификаторы, геометрию и происхождение записей. Два исходных листа сохранены. Технические проверки и список спорных случаев хранятся в Markdown рядом с книгой.

PASS означает подтверждённый численный или структурный факт. FAIL означает измеримое нарушение. UNVERIFIED означает, что нужны дополнительные данные или правило заказчика. Промышленный шаблон рабочего Excel, справочник типов и окончательная нумерация требуют согласования.

## Исходники и сборка

В PowerShell из папки исходников:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
.\.venv\Scripts\python.exe -m pytest
```

Для тестов реальной книги задайте `MINEFLOW_REAL_XLSX` и `MINEFLOW_INPUT_KEY`. Для воспроизведения поставленного Excel и отчёта используйте:

```powershell
.\.venv\Scripts\python.exe -m tools.case_release 'C:\путь\Осевые для Моя профессия ИТ.XLSX' --out release
```

```powershell
.\.venv\Scripts\python.exe -m PyInstaller --noconfirm --onedir --windowed --name MineFlowStudio --exclude-module IPython --exclude-module pandas --exclude-module scipy --exclude-module tkinter --exclude-module lxml --hidden-import vtkmodules.vtkRenderingOpenGL2 main.py
```

Сборка появится в `dist/MineFlowStudio`. Для переноса скопируйте папку целиком.
