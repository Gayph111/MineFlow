# MineFlow Studio 0.5

Windows-приложение для обработки осевых выработок, просмотра плана и 3D, расчёта участков Порода / Руда и выгрузки Excel.

## Запуск и нужный режим нумерации

1. Распакуйте архив целиком. Запустите MineFlowStudio.exe рядом с папкой _internal.
2. Откройте исходный Excel или сохранённый проект MineFlow.mineflow.json. Для защищённого Excel введите его пароль.
3. В «Правила → Что нумеровать» выберите «Целые линии на плане».
4. Выберите направление «С севера на юг» и область «Заново на каждом горизонте и рудном теле».
5. Нажмите «Обработать».
6. На горизонте −350 исходной книги показаны шесть линий с номерами 1–6 сверху вниз. Породная и рудная части одной прямой имеют общий номер, даже если в Excel у них разные JOIN.
7. При нажатии с любой стороны одной линии свойства и подсказка показывают её номер.
8. Через «Экспорт» сохраните рабочий Excel и отчёты.

Для новых книг этот режим и предварительная нумерация включены сразу. Старые проекты с режимом «Оси целиком» теперь используют исправленную геометрическую логику. Если проект использовал другой режим, выберите «Целые линии на плане» явно.

## Что считается линией

Прямые части одного тела и горизонта объединяются при совпадении, перекрытии или непрерывном продолжении в пределах заданного допуска. Разные записи JOIN могут входить в одну линию. Изогнутый переход сохраняется в геометрии, отделяется в существующих вершинах и не объединяет номера соседних прямых. У перехода нет отдельного порядкового номера; свойства могут показывать «Переход 1 ↔ 2».

Одна исходная запись Excel может содержать две прямые и переход между ними. На листе «Оси» для такой записи перечисляются номера линий, например «1, 2». Это номера двух разных прямых внутри одной записи, а не разные номера породной и рудной частей одной прямой.

По умолчанию основное направление прямых определяется по преобладающим отрезкам отдельно на каждом горизонте и рудном теле. Оно может быть задано вручную через азимут от NORTH по часовой стрелке. Допуск отклонения от основного направления — 2°. Допуск стыковки — 0,01 единицы исходных координат. Эти настройки доступны в правилах. На геометрии с другими направлениями проверьте настройку перед обработкой.

Счёт идёт по центрам целых линий. Доступны север → юг, юг → север, запад → восток, восток → запад, порядок по RL и собственный азимут или расстояние. Можно начинать счёт на каждом горизонте или продолжать по всему телу. При непрерывном порядке сверху вниз RL −350 идёт перед −500.

Режим «Отдельные записи Excel» сохраняет прежнюю нумерацию по JOIN. Режим «Связанные Порода — Руда» объединяет номера исходных записей только по однозначной установленной паре. Для результата как на схеме 1–6 используется основной режим «Целые линии на плане».

## Разделение и длины

Разделение по границе руды и выделение прямых для нумерации — отдельные операции. Настройка «Не разделять по границе руды» отключает разрезание по контуру. Прямые и переходы всё равно отделяются для правильной нумерации.

Исходные координаты не сдвигаются. При пересечении контура вычисляются точки пересечения, RL интерполируется при наличии двух высот. Длины считаются в XY или XYZ. Сумма длин всех частей каждой исходной записи сохраняется. Контуры, исходные записи и их связь с рабочими частями остаются доступны.

Установление пар Порода — Руда работает отдельно от нумерации целых линий. Неоднозначные пары попадают в подтверждения. Они не мешают объединить геометрически непрерывную прямую.

## Рабочий Excel

Сохраняются два исходных листа и добавляются четыре рабочих:

- «Оси» — исходные записи JOIN, длины, номера содержащихся в них линий и данные из сопроводиловки.
- «Участки» — расчётные части, категории, длины, общий номер прямой, роль «Линия» или «Переход», группа нумерации и соседние линии перехода.
- «Точки участков» — точные вершины и их происхождение.
- «Связи участков» — установленные пары Порода — Руда.

На исходной книге получаются 36 целых линий на семи горизонтах: 125 прямых расчётных частей, 14 частей переходов и 2 части с недостаточными данными. Всего 141 рабочая часть. На горизонте −350 ровно шесть прямых линий. Число частей выросло с 126, поскольку переходы отделяются от прямых без изменения общей геометрии и длины.

## Проверка

«Пройдено» — конкретная проверка подтвердила результат. «Ошибка» — найдено измеримое нарушение. «Требует подтверждения» — нужны данные или согласование. «Предварительно» в рабочих данных означает расчёт по выбранным настройкам до производственного согласования.

Проверка читает сохранённый Excel, независимо восстанавливает прямые, нумерацию, роли переходов, длины, категории, исходные данные и связи. Счётчики показывают пункты проверки, а не число проблемных выработок. На исходной книге осталось 27 пунктов подтверждения: 21 по связям в 7 записях, 4 по неполным данным в 2 записях и 2 общих пункта по правилам и эталону.

## Проекты и исходники

«Сохранить проект» записывает путь к исходному Excel и настройки в .mineflow.json. Пароль не сохраняется. Для переноса нужен исходный Excel; приложение позволяет указать новое расположение.

В PowerShell из папки исходников:

    py -3.12 -m venv .venv
    .\.venv\Scripts\python.exe -m pip install -r requirements.txt
    .\.venv\Scripts\python.exe main.py
    .\.venv\Scripts\python.exe -m pytest

Для тестов на исходной книге задайте переменные MINEFLOW_REAL_XLSX и MINEFLOW_INPUT_KEY. Выпуск рабочей книги:

    .\.venv\Scripts\python.exe -m tools.case_release 'C:\путь\Исходный.xlsx' --out release

Сборка Windows x64 включает Python и библиотеки. Для 3D нужен системный драйвер OpenGL. Переносится папка целиком.
